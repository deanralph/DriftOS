Administrator setup

The helper manages its own share definitions and no-login SMB accounts. It does not install packages, open firewall ports or start services.

Install the native Samba/NFS server packages. For SMB, back up /etc/samba/smb.conf, then add this at its end and validate with testparm -s:
[global]
    include = /etc/samba/driftos-shares.conf
